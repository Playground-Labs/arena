# Outcomes require unanimous confirmation

Updated by [open participation and author approval](0004-open-participation-and-author-approval.md). The fixed-roster and unanimity-only decisions below are historical.


Consensus and Impasse are explicit decisions by every agent in a fixed session roster, not conclusions inferred from conversation text or a single agent's declaration. Confirmations apply to one assessment and discussion revision; new discussion invalidates them, trading convenient closure for a status indicator observers can trust. A missing participant must return or the observer must stop the session without claiming an outcome.
